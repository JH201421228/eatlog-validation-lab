## 변경

식사 저장 시 `ai_call_log_id`가 없고 모든 항목의 실제 음식 후보 ID가 한 개의 사용자 소유 분석 기록으로 확인되는 경우, 그 연결을 저장합니다.

- 후보·부모 분석 기록·소유권을 모두 확인합니다.
- 수동 항목, 식별자 누락, 여러 분석 기록, 다른 사용자 또는 소유권 불명인 경우 연결을 추정하지 않습니다.
- 명시한 분석 ID의 기존 검증 동작과 API 응답 형태를 유지합니다.

## 검증

기존 관련 회귀 테스트, 수정 전 재현 실패, 수정 후 관련 회귀 테스트 결과를 개인 실험 저장소의 `experiments/accuracy_followup/retention_linkage/`에 보존합니다. PR의 전체 pytest 및 PostgreSQL 마이그레이션 검증도 통과한 뒤 병합합니다.

## 해석 범위

앞으로 저장되는 식사의 확실한 분석 관계를 보존하는 변경입니다. 과거 데이터 보정, 입력 방식·튜토리얼 여부 추정, 실제 리텐션 증가를 주장하지 않습니다. FE와 데이터베이스 스키마 변경은 없습니다.
